# VECTOR//CORE - AWAKENING VECTOR

ブラウザーで動作するカードバトルゲームです。

## 起動方法

### ローカルで遊ぶ

1. このリポジトリをダウンロードするか、`Code` → `Download ZIP` から取得します。
2. ZIPを展開します。
3. `index.html` をブラウザーで開きます。

一部のブラウザー機能やオンライン対戦は、`file://` で開いた場合に制限されることがあります。その場合はGitHub PagesなどHTTPSで配信してください。

### GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成します。
2. このプロジェクトのファイルとフォルダーを、リポジトリの最上位にアップロードします。`index.html` が最上位にあることを確認してください。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Build and deployment** の **Source** を `Deploy from a branch` にします。
5. Branchを `main`、フォルダーを `/(root)` にして保存します。
6. 公開処理が終わると、同じPages設定画面にサイトURLが表示されます。

## Vercelで公開する

このプロジェクトはHTML/CSS/JavaScriptだけで動く静的サイトです。Next.jsなどのフレームワークやビルド工程は不要です。

### GitHub経由でデプロイ（おすすめ）

1. このフォルダーの中身をGitHubリポジトリの最上位にアップロードします。`index.html` が最上位にあることを確認してください。
2. [Vercel](https://vercel.com/) にログインし、GitHubアカウントを接続します。
3. **Add New → Project** を選び、`vector-core` リポジトリを **Import** します。
4. Project Settingsで次のように設定します。
   - **Framework Preset:** `Other`
   - **Root Directory:** `./`（リポジトリ直下）
   - **Build Command:** 空欄（Overrideを有効にして空欄にする必要はありません）
   - **Output Directory:** 空欄（Vercelの既定値を使用）
   - **Install Command:** 空欄（依存パッケージなし）
5. **Deploy** を押します。

### ZIPから直接デプロイする場合

VercelのダッシュボードやCLIの利用方法は変更される場合があります。確実な方法は、先にGitHubへアップロードしてから上記の手順でImportすることです。

### 公開後の確認

- 発行された `vercel.app` のURLを開き、ホーム画面が表示されるか確認します。
- ブラウザーの再読み込み後もCSSと音声が読み込まれるか確認します。
- オンライン対戦はWebRTCを使うため、接続コード交換と通信環境の確認が別途必要です。
- セーブデータはブラウザー内に保存され、端末間では自動同期されません。

## オンライン対戦について

オンライン対戦はWebRTCを使うP2P方式です。部屋を作る側が接続コードを共有し、参加側が返信コードを返す2段階方式です。接続確立にはGoogleの公開STUNサーバーを参照します。Vercelはゲーム画面の配信に使い、対戦データは原則として2台のブラウザー間を直接流れます。ネットワーク環境によってはP2P接続できない場合があります。モバイル回線などで一時的に切断状態になっても、15秒間は復帰を待つようにしています。

## 注意

- このプロジェクトはHTML/CSS/JavaScriptによる静的サイトです。サーバー側のビルド工程はありません。
- セーブデータはブラウザー側に保存されます。別の端末・ブラウザー間では自動同期されません。
- 公開リポジトリにする前に、収録した音声・画像・フォント等の利用権限を確認してください。
- このリポジトリにはライセンスファイルを付けていません。第三者による利用・改変・再配布の条件を明確にしたい場合は、権利関係を確認したうえでライセンスを選んでください。

## 開発・動作確認

JavaScriptファイルは通常のブラウザー用スクリプトとして読み込まれます。編集後、各ファイルの構文確認にはNode.jsが利用できます。

```bash
for f in src/*.js; do node --check "$f"; done
```


## 今回のゲーム性改善

- CPUはカードを単純なコスト順ではなく、盤面・手札・墓地・相手のCHAIN/CORE SHIELDを見て選ぶように変更しました。
- VECTORはSPD/CHAIN、NULLはDEF/妨害、NOVAはATK/盤面制圧、ECHOは墓地利用を評価します。
- 効果を使う対象がいないACTIONや、上限に達したCORE SHIELDを増やすACTIONなど、空振りしやすい行動を避けます。
- S06のルート選択をS07の会話とS08の初期ボーナスに反映しました。ROUTE AはCORE SHIELD+1、ROUTE Bは追加ドロー+1です。

※これはCPUの判断ロジックとルート演出の改善です。カードの勝率・先攻後攻差・陣営別勝率を実測したものではありません。正式なカードバランス調整には対戦ログを集めたプレイテストが必要です。
